## 📁 Repository Structure
To keep this repository organized, **every team must place their project inside a dedicated team folder**. 

```text
BTC-2026/
│
├── teams/
│   ├── your-team-name/       <-- ALL your code goes here!
│   │   ├── .gitignore        <-- Must include your own local gitignore
│   │   ├── README.md         <-- Must include setup instructions
│   │   └── src/
│   │
│   └── another-team-name/
│
└── README.md

```
## 🚀 How to Submit Your Project

1. **Fork & Clone:** Fork this repository to your own GitHub account and clone it locally.
2. **Create Your Branch:** Create a new branch for your team (e.g., `git checkout -b team-name-submission`).
3. **Build Your Code:** Create a folder inside `teams/` with your exact team name. Build your entire project *inside* that folder. **You must include a `.gitignore` file specific to your tech stack inside your team folder.**
4. **Open a Pull Request:** When you are ready to submit, push your branch and open a Pull Request against the `main` branch of this repository. Fill out the provided PR template completely.
